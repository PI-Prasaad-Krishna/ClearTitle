# ClearTitle

ClearTitle is a prototype high-end digital forensics tool for the Indian used car market. It provides a heavily stylized, brutalist interface for aggregating and analyzing vehicle data across multiple national registries (VAHAN, IIB, NCRB, and NIC eChallan).

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS v4, Three.js (`@react-three/fiber`), Framer Motion, Lenis.
- **Backend:** Python, FastAPI, Uvicorn.

## Key Features
- **High-End Editorial UI:** Uses `mix-blend-difference`, massive typography, and custom 3D WebGL particle tunnels to create an immersive, premium experience.
- **Async Aggregation Engine:** The Python backend simulates a high-performance concurrent "fan-out" architecture, querying 4 mock databases simultaneously via `asyncio.gather()`.
- **Dynamic Risk Scoring:** The frontend dynamically shifts into warning (amber) or critical (red) states based on the severity of the risk score generated by the API.

## Local Development Setup

### 1. Frontend
```bash
cd frontend
npm install
npm run dev
```
*The frontend will run on `http://localhost:5173`.*

### 2. Backend
```bash
cd backend
python -m venv venv
```

**Activate the virtual environment:**
- **Windows:** `.\venv\Scripts\activate`
- **Mac/Linux:** `source venv/bin/activate`

**Install dependencies and run the server:**
```bash
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```
*The backend API will run on `http://localhost:8000`.*

## Demo Usage
Once both servers are running, navigate to the frontend:
- Enter any random Indian license plate for randomized mock data.
- Enter exactly **`MH01AB1234`** to trigger the hardcoded worst-case scenario (Active Stolen FIR, Total Loss Accident, Maximum Pending Challans).
